# BachViet - Cổng Thông Tin Giáo Dục

Một nền tảng cấp thiết kế theo mô hình của daklak.edu.vn, cung cấp các chức năng quản lý thông tin giáo dục, tin tức, thông báo và tài nguyên học tập.

## 🚀 Tính Năng Chính

- ✅ Trang chủ với tin tức, thông báo mới nhất
- ✅ Quản lý bài viết (Create, Read, Update, Delete)
- ✅ Hệ thống phân quyền (Admin, Editor, Viewer)
- ✅ Tìm kiếm và lọc nội dung
- ✅ Đăng nhập/Đăng ký người dùng
- ✅ Giao diện responsive (Mobile-friendly)
- ✅ Quản lý thư viện tài nguyên
- ✅ Thống kê và báo cáo

## 🛠️ Công Nghệ Sử Dụng

- **Frontend**: Next.js 14, React 18, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Tokens)

## 📦 Cài Đặt

```bash
git clone https://github.com/TanThinh1/BachViet.git
cd BachViet
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000)
